# Студия медитаций

Личная студия Елены Кирсановой: запись голосовых медитаций, наложение на медитативную музыку и создание готовых MP3 для продажи и отправки клиентам.

Работает в браузере на iPhone, Android, Windows и macOS, устанавливается на экран «Домой» как приложение, после первого открытия работает и без интернета.

## Что лежит в репозитории

| Файл / папка | Зачем |
|---|---|
| `index.html` | Само приложение (собранное, всё в одном файле) |
| `manifest.webmanifest` | Чтобы приложение устанавливалось на телефон/компьютер |
| `sw.js` | Офлайн-режим |
| `icons/` | Иконки приложения |
| `src/` | Исходники для доработок (`app.src.html`, `engine.js` — звуковой движок). Сборка: `python3 src/build.py` |

## Публикация

Микрофон в браузерах работает только по защищённому адресу (https), поэтому студию нужно открыть с сайта, а не из файла.

**Рекомендуемый вариант — Cloudflare Pages, адрес `studio.elenakirsanova.com`:**
1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git → выбрать репозиторий `studio`.
2. Framework preset: **None**, Build command: *пусто*, Build output directory: `/`. Save and Deploy.
3. В проекте Pages → Custom domains → Set up a custom domain → `studio.elenakirsanova.com` → подтвердить.
4. После этого репозиторий можно сделать приватным (GitHub → Settings → General → Change visibility → Private) — Cloudflare продолжит публиковать.

Запасной вариант — GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)` → Save. Адрес: `https://elenakirsbg.github.io/studio/` (работает, пока репозиторий публичный).

## Важно про данные

Записи, черновик и библиотека хранятся **в браузере того устройства**, где вы работаете. На другое устройство медитации переносятся через «Библиотека → Скачать архив» и «Загрузить архив». Регулярно скачивайте архив библиотеки — это ваша резервная копия.

## Лицензии

Встроенная музыка синтезируется самим приложением и принадлежит автору медитаций. Кодирование MP3 — библиотека lamejs (LGPL-3.0, см. `src/LAMEJS-LICENSE.txt`).
